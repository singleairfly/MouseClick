# 虚拟电厂小程序页面设计

## 项目概述

这是一个虚拟电厂（VPP - Virtual Power Plant）小程序的前端页面设计，用于管理分布式能源资源、监控能源状态、参与需求响应和查看收益统计。

## 页面列表

### 1. 首页/仪表盘 (Home Dashboard)
- **功能描述**: 整体能源状态概览，是用户进入小程序后的第一个页面
- **主要模块**:
  - 用户欢迎卡片（含天气信息）
  - 能源概览（今日发电、用电、储能电量、收益）
  - 实时功率图表（发电功率、用电功率、净功率曲线）
  - 快捷功能入口（设备管理、能源监控、需求响应、收益中心）
  - 调度任务列表（进行中、待执行、已完成的任务）

### 2. 设备管理 (Devices)
- **功能描述**: 管理接入虚拟电厂的所有分布式能源设备
- **主要模块**:
  - 设备统计（总数、在线、离线）
  - 设备分类筛选（全部、光伏、储能、充电桩、负荷）
  - 设备卡片列表:
    - 光伏阵列（发电功率、今日发电量、效率）
    - 储能系统（电量百分比、充放电功率、温度）
    - 充电桩（充电功率、已充电量、预计完成时间）
  - 离线设备提示

### 3. 能源监控 (Monitor)
- **功能描述**: 详细的能源数据监控和分析
- **主要模块**:
  - 时间筛选（今日、本周、本月、本年）
  - 能源总览（总发电量、总用电量及趋势）
  - 能源流向图（光伏→能源中心→负荷/储能/电网）
  - 发电曲线图（发电与用电对比曲线）
  - 能源统计（自用率、上网率、碳减排量）

### 4. 需求响应 (Response)
- **功能描述**: 参与电网需求响应，响应削峰填谷调度
- **主要模块**:
  - 响应状态卡片（当前响应任务进度）
  - 可调度资源列表（储能系统、空调负荷、充电桩）
  - 待响应任务:
    - 削峰响应（减少用电负荷）
    - 填谷调度（增加用电负荷）
  - 响应历史记录

### 5. 收益中心 (Income)
- **功能描述**: 展示用户的收益和账单信息
- **主要模块**:
  - 累计总收益展示
  - 收益分类（售电收入、响应收入）
  - 收益趋势图（周/月/年柱状图）
  - 收益明细列表:
    - 售电收入
    - 削峰响应奖励
    - 购电支出
    - 光伏补贴
  - 可提现金额及提现按钮

### 6. 用户中心 (Profile)
- **功能描述**: 用户个人信息和系统设置
- **主要模块**:
  - 用户头像和信息
  - 会员等级展示
  - 运营数据（运行天数、接入设备数、响应次数）
  - 功能菜单:
    - 我的订单
    - 电费账单
    - 合同管理
    - 客服中心
    - 帮助与反馈
    - 关于我们
    - 系统设置

## 技术特点

- **移动端适配**: 采用响应式设计，最大宽度414px，适配各种手机屏幕
- **现代UI设计**: 使用渐变色、卡片式布局、圆角设计
- **交互动画**: 页面切换动画、按钮点击反馈、数据更新动画
- **图标系统**: 使用 Remix Icon 图标库
- **实时数据模拟**: JavaScript模拟实时功率数据更新

## 设计说明

### 配色方案
- 主色调: #1890ff (蓝色)
- 辅助色: #36cfc9 (青色)
- 成功色: #52c41a (绿色)
- 警告色: #faad14 (橙色)
- 危险色: #ff4d4f (红色)

### 设计原则
1. **简洁直观**: 信息层级清晰，重要数据突出显示
2. **功能导向**: 快捷入口方便用户快速访问核心功能
3. **数据可视化**: 使用图表、进度条等直观展示数据
4. **响应式交互**: 提供视觉反馈增强用户体验
